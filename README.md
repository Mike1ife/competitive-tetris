## Note
- For now, we can use down key to move tetrominos down by 1 cell, but under agent context we shouldn't have this key. Instead, next states are generated by try all the combinations of rotation and moving left/right while always dropping by 1 (see reference repo). It's good because we won't need to keep track of "time" in the environment, which is needed if we allow speed up.
- Therefore, it should be fair to not allow user to use down key.
- We let agent to call ```execute``` to perform actions just like hw1.
- Current implementation is solely used for PVP.
- Score calculation should be refined so clearing more lines together gets bonus.
- May exist some bugs regarding the garbage lines (I'm too bad to play to 2 players on my own, so it's difficult to try playing with garbage lines). My set up for garbage line is it contain 1~3 holes. May modify it in the future.
